# نسخه جديد — تطبيق حظر تطبيقات (مشروع جديد مستقل)

هذا **مشروع جديد تمامًا** (Clean-room) مش تعديل على تطبيق Mindful Lock الأصلي. لا يستخدم أي من كوده أو موارده أو أسماء حزمه، ولا يتصل بخوادمه، ولا يتجاوز أي ترخيص أو فوترة.

## الاسم والمالك
- اسم التطبيق المعروض: **نسخه جديد**
- اسم الحزمة: `com.assem.copyapp`
- اسم المالك الافتراضي داخل التطبيق: **عاصم**

## كود الخصم
افتح بطاقة **Premium** وأدخل:

```
gdNeooYe8
```

بعد الضغط على «تفعيل الكود» يتحول التطبيق إلى Premium محليًا، وتتغير الحدود إلى 24 ساعة / جلسات غير محدودة.

> تفعيل تجريبي محلي داخل هذا التطبيق الجديد فقط، بلا علاقة بـ Play Store أو PairIP أو الحساب الأصلي.

## أهم الخصائص في الإصدار 1.1
1. **حظر كامل بدل Overlay متقطع**
   - `AccessibilityService` يكتشف فتح أي تطبيق محظور أثناء الجلسة.
   - بدل نافذة Overlay تُعرض، يُفتح **BlockingActivity** كشاشة كاملة في المقدمة، فيُوقف التطبيق المحظور فعليًا ولا يمكن التحكم به.
   - زر الرجوع/OS Recents/Home تُعترض أثناء الحظر، ومحاولة فتح التطبيق مجددًا تُعيد شاشة الحظر فورًا.
   - شاشة الحظر تعرض العدّ التنازلي، شريط تقدم، زر العودة للرئيسية، اتصال طوارئ، وإنهاء الجلسة.
   - عند الحظر يُقتل التطبيق في الخلفية، ومحاولة فتح «التطبيقات الحديثة» تُغلق وتُعاد شاشة الحظر.
2. **واجهة محسّنة**
   - تصميم داكن ببطاقات، شريط حالة، مؤقّت كبير، قائمة تطبيقات مع بحث وصور أيقونات وتحديد الكل/إلغاء الكل.
   - اختيارات سريعة للمدة (15/30/60/120 دقيقة) + إدخال مخصص.
   - لوحة صلاحيات توضّح المفعّل وغير المفعّل، وزر مراجعة الصلاحيات، وزر Device Admin.
3. **جلسات ومؤقت**
   - إشعار مستمر بالوقت المتبقي، وزر لفتح التطبيق.
   - إشعار عند انتهاء الجلسة، وإغلاق تلقائي لشاشة الحظر.
   - استعادة الجلسة بعد إعادة تشغيل الجهاز عبر `BootReceiver`.
4. **حدود الخطة**
   - مجاني: 6 ساعات كحد أقصى + 4 جلسات يوميًا.
   - Premium: 24 ساعة + جلسات غير محدودة.
5. **جدولة يومية**
   - وقت بداية/nهاية وتفعيل متكرر عبر `AlarmManager`، مع إمكانية إلغاء الجدول.
6. **أداء**
   - أحداث Accessibility مقتصرة على `TYPE_WINDOW_STATE_CHANGED` + فحص دوري خفيف كل 800ms.
   - لا توجد إعادة إنشاء متكررة لنوافذ Overlay.
7. **وضع التركيز الشديد**
   - حظر كل التطبيقات أثناء الجلسة عدا الهاتف والرسائل والتطبيق نفسه؛ لا تحتاج لتحديد قائمة يدويًا.
8. **نظافة الجهاز**
   - إحصاءات زمن الشاشة لكل تطبيق اليوم (تحتاج صلاحية Usage Stats).
   - تنظيف التطبيقات في الخلفية من قائمة قابلة للاختيار دون حذف بياناتها.
   - بطاقة تعرض نسبة البطارية، المساحة المتاحة، والرام المتاحة.
9. **إحصاءات التركيز**
   - جلسات اليوم، دقائق التركيز اليوم، وآخر 5 جلسات محفوظة محليًا.
10. **صلاحيات أوضح**
   - لوحة حالة Accessibility / Usage Stats / الإشعارات / البطارية / Device Admin.

## البناء
البناء يتم سحابيًا عبر GitHub Actions في المستودع `ACona1/NewCopyApp` دون تثبيت Android SDK محليًا.
ملف الـ workflow: `.github/workflows/build.yml`.
الناتج: artifact باسم `NewCopyApp-debug` يحتوي `app-debug.apk`.

## ملفات مهمة
- `SessionManager.kt` — الجلسات، الحدود، كود الخصم، ونسبة التقدم.
- `AppBlockingAccessibilityService.kt` — كشف التطبيق المحظور وإطلاق شاشة الحظر.
- `BlockingActivity.kt` — شاشة الحظر الكاملة والعدّ التنازلي.
- `TimerService.kt` — المؤقت والإشعارات وإغلاق الحظر عند النهاية.
- `MainActivity.kt` — الواجهة والصلاحيات والجدولة.
- `AndroidManifest.xml` — المكوّنات والصلاحيات.

## ملاحظات
- Premium هنا حالة محلية في SharedPreferences؛ لا يوجد تحقق خادمي أو فوترة حقيقية (مقصود تصميمًا).
- الصلاحيات المطلوبة عمليًا: Accessibility service + الإشعارات (Android 13+) + تجاهل تحسين البطارية (مستحسن). Device Admin اختياري لتقوية الإجبار.
