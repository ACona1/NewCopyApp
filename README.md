# نسخه جديد — تطبيق حظر تطبيقات (مشروع جديد مستقل)

هذا **مشروع جديد تمامًا** (Clean-room) مش تعديل على تطبيق Mindful Lock الأصلي. لا يستخدم أي من كوده أو موارده أو أسماء حزمه، ولا يتصل بخوادمه، ولا يتجاوز أي ترخيص أو فوترة.

## الاسم والمالك
- اسم التطبيق المعروض: **نسخه جديد**
- اسم الحزمة: `com.assem.copyapp`
- اسم المالك الافتراضي داخل التطبيق: **عاصم** (يظهر في شاشة الحالة وبعد تفعيل Premium).

## كود الخصم
افتح شاشة **Premium / إدخال كود الخصم** وأدخل:

```
gdNeooYe8
```

بعد الضغط على «تفعيل»:
- يتحول التطبيق فورًا إلى Premium محليًا.
- تتغير الحدود من 6 ساعات / 4 جلسات يوميًا إلى 24 ساعة / جلسات غير محدودة.
- يظهر «Premium مفعّل» واسم المالك «عاصم» في الشاشة الرئيسية.

> ملاحظة: هذا تفعيل تجريبي محلي داخل هذا التطبيق الجديد فقط. ليس له علاقة بـ Play Store أو PairIP أو حساب Mindful Lock الأصلي.

## أهم الخصائص
1. **حظر إجباري للتطبيقات**
   - `AccessibilityService` يكتشف التطبيق الذي فُتح.
   - لو كان ضمن القائمة المختارة أثناء جلسة نشطة، يظهر شاشة Overlay كاملة تمنع الاستخدام.
   - زر «العودة للشاشة الرئيسية» يستخدم `GLOBAL_ACTION_HOME`؛ والخدمة تعيد الحظر فور محاولة فتح التطبيق again.
   - زر «اتصال طوارئ» يفتح تطبيق الهاتف، وزر «إنهاء جلسة التركيز» لإيقاف الجلسة يدويًا.
2. **جلسات تركيز**
   - اختيار المدة بالدقائق، مؤقت تنازلي في إشعار مستمر (`TimerService`).
   - استعادة الجلسة بعد إعادة تشغيل الجهاز عبر `BootReceiver`.
3. **حدود الخطة**
   - مجاني: 6 ساعات كحد أقصى + 4 جلسات يوميًا.
   - Premium: 24 ساعة + جلسات غير محدودة.
4. **جدولة يومية**
   - اختيار وقت البداية والنهاية، وتفعيل جدول متكرر يوميًا عبر `AlarmManager`.
5. **صلاحيات**
   - شاشة زر واحدة لطلب: Overlay، Accessibility، Usage Stats، الإشعارات.
   - زر منفصل لتفعيل Device Admin.
6. **اختيار التطبيقات**
   - قائمة بكل تطبيقات المستخدم (بدون تطبيقات النظام) معCheckBox لحفظ القائمة المحظورة.

## طريقة البناء
1. افتح Android Studio (يفضّل مع JDK 17) واختار **File > Open** وحدد مجلد `NewCopyApp`.
2. انتظر Gradle Sync (ينزّل AGP 8.5.2 وKotlin 1.9.24 والمكتبات).
3. شغّل التطبيق على جهاز/محاكي API 26+.
4. اضغط «تفعيل الصلاحيات المطلوبة» وفعّل يدويًا:
   - «Display over other apps»
   - «Usage access»
   - الخدمة الخاصة بالتطبيق من Accessibility
   - الإشعارات (على Android 13+)
5. فعّل Device Admin من الزر الثاني (اختياري لكنه يقوّي الإجبار).
6. أدخل كود الخصم ثم ابدأ جلسة.

## ملفات مهمة
- `app/src/main/java/com/assem/copyapp/SessionManager.kt` — منطق الجلسات والحدود وكود الخصم.
- `app/src/main/java/com/assem/copyapp/AppBlockingAccessibilityService.kt` — كشف التطبيق وعرض شاشة الحظر.
- `app/src/main/java/com/assem/copyapp/TimerService.kt` — المؤقت والإشعار المستمر.
- `app/src/main/java/com/assem/copyapp/MainActivity.kt` — الواجهة والصلاحيات والجدولة.
- `app/src/main/AndroidManifest.xml` — المكوّنات والصلاحيات.

## حدود معروفة
-Premium هنا حالة محلية في SharedPreferences؛ لا يوجد تحقق خادمي ولا فوترة حقيقية (مقصود بهذا تصميمًا).
- لا يوجد Firestore/Remote Config/AdMob/FCM في هذه النسخة؛ أضفها لو حببت لاحقًا.
- لم أضف Widgets ولا قائمة مواقع بالغة؛ يمكن إضافتها في مرحلة ثانية لو طلبت.
- لم أتمكن من التجميع هنا لغياب Android SDK/Gradle في البيئة الحالية؛ المشروع مكتوب ليُبنى في Android Studio.
